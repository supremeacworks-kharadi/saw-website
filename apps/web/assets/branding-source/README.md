# Branding Source Assets

This folder keeps the original, editable branding files.

## Files

- `logo-full-source.png`: full horizontal logo source.
- `logo-icon-source.png`: icon-only logo source.

## Publish workflow

1. Replace source files here when branding updates.
2. Export optimized web-ready files to `apps/web/public/branding/`:
   - `logo-full.png`
   - `logo-icon.png`
   - `favicon.png`
3. Keep filenames stable so no code changes are needed.
